# GameOn

🔗 [Live Demo](https://julien-ba.github.io/project4/starterOnly/index.html)

## Description

This project was developed as part of the OpenClassrooms Web Developer program, focusing on JavaScript form validation.
GameOn is a landing page for a gaming events company featuring a dynamic registration form.

## Project Goals

-   Implement form validation using Vanilla JavaScript
-   Handle user input and provide real-time feedback
-   Create responsive form interactions
-   Ensure accessibility standards
-   Improve existing HTML/CSS structure

## Technical Features

-   JavaScript:
    -   Form validation with regex patterns
    -   Custom error messages
    -   Event handling and DOM manipulation
    -   Real-time input validation
    -   Form submission management
-   Code Improvements:
    -   Restructured HTML for better semantics
    -   Converted CSS to SASS
    -   Enhanced responsive design
    -   Improved accessibility
